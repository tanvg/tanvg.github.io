# Tanvi Garg — Portfolio

A static portfolio designed for GitHub Pages.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `portfolio`).
2. Upload all files from this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

If your repository is named `YOURUSERNAME.github.io`, the site will be available at that address. Otherwise GitHub Pages will give you the project URL.

## Customize
- Edit `index.html` for copy and links.
- Edit `style.css` for visual design.
- Replace `resume.pdf` whenever your resume changes.
- Add your GitHub URL to the contact links once ready.
